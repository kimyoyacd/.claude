# 사운드 디자인 + 감정 프레임 — 게임음이 현실을 침투하는 구조

> **핵심 개념**: 태국 광고의 "선택의 순간" 정지 기법 + 게임 고유음향의 심리 침투  
> **목표**: 클리셰 극복 — "이건 추억 광고가 아니라, 게임과 현실의 경계 붕괴"를 음향으로 표현

---

## Part 1: 회상 오프닝 (0~12s) — 게임음의 "기준선"

### 음향 구조: 3 레이어
1. **BGM**: 8bit 원작 음악 (기준선)
2. **게임 효과음**: 부스터, 카운트다운, 드리프트음
3. **현장음**: PC방 앰비언스 (키보드 소리, 아이들 목소리)

### 장면별 상세 사운드 큐

#### 🎬 컷 1-1: 시간 표지 (0~1.5s)
```
타임라인:
0.0s: PC방 시동음(전자음 "부릉~") 페이드인 + 새소리 배경
0.3s: 8bit BGM 아주 낮은 음량(기대감)
0.8s: 새소리 페이드아웃, PC 팬음(쿨러)만 남음
1.2s: 발걸음 소리 (누군가 들어옴)
1.5s: 의자 끌리는 소리 시작

감정 포인트: "옛날 PC방에 들어서는 그 느낌" (일상 복원)
```

#### 🎬 컷 1-2: 4명의 입장 (1.5~3s)
```
1.5s~2.0s: 의자 4개 끌리는 소리 (좌→우로 천천히, 각각 다른 톤)
  - 첫 번째 아이(주인공): 무겁고 차분한 끌림음
  - 두 번째(A친구): 가볍고 재빠른 끌림음
  - 세 번째(B친구): 중간 톤
  - 네 번째(C친구): 가장 빠르고 에너지 넘침

2.0s: 모니터 부팅 소리들(4개 동시) → "윙~" 하는 전자음
2.3s: 아이들 목소리 겹침
  - "어 너 어디 갔었어" (B친구, 낮은 톤)
  - "어제 꿈에 너 나왔어" (여자아이, 높은 톤)
  - "진짜?" (주인공, 중간 톤, 놀라움)
  - "아 맞다맞다" (C친구, 흥분)

2.8s: 작은 웃음소리들(자연스러운 중첩)
3.0s: 모니터 마우스 클릭음 시작(톡톡톡)

감정 포인트: "우리 다 같이 온 것 같은 자연스러움" (재결합의 기쁨)
```

#### 🎬 컷 1-3: 게임 로딩 (3~4.5s) — 게임음의 첫 신호
```
3.0s: 마우스 클릭음(톡톡톡) 강조
  - 주인공: 일정한 리듬 (톡-톡-톡)
  - A친구: 불규칙한 리듬 (톡톡-톡톡톡) [긴장]
  - B친구: 느린 리듬 (톡...톡...톡) [신중]
  - C친구: 빠른 리듬 (톡톡톡톡톡!) [흥분]

3.5s: 게임 UI 음성 페이드인 (매우 낮은 음량)
  - "딩" (선택음, 각 모니터마다)
  - "윙~" (로딩음)

4.0s: 아이들 목소리
  - "너 이거 봤어?" (A친구)
  - "음... 몰라" (B친구)
  - "야 빨리!" (C친구)

4.3s: 게임 로딩 완료음 (낮은 피치의 "딕")
4.45s: 게임이 준비됨을 알리는 신호음 (높은 피치 "핑~")

감정 포인트: "각자의 성격이 마우스 리듬에서 드러남" (캐릭터성)
```

#### 🎬 컷 1-4: 라인업 준비 (4.5~7s)
```
4.5s: 8bit BGM 이전 음량의 2배로 상승
  - 박자감 명확해짐 (기대의 상승)

4.7s~6.0s: 부스터 게이지 찬다는 음향 (게임 UI음)
  - 각 모니터마다 약간 다른 타이밍
  - "슈슈슈~" (게이지 차오르는 음, 점진적 상승)
  - 마지막에 "핑!" (100% 도달 신호)

6.0s: 4개 모니터 모두 게이지 100%
  - 동시에 4개의 "핑!" 소리

6.2s~6.8s: 아이들의 긴 호흡음과 마우스 준비음
  - 주인공: 조용한 호흡 (차분)
  - A친구: "후~" (긴장 풀기)
  - B친구: "..." (무언의 집중)
  - C친구: "흠흠" (흥분 참기)

6.8s: 게임 음성 "Ready..."
  - 로봇 음성(합성음, 게임 시스템음)
  - 저음 ~ 고음으로 상승하는 톤

감정 포인트: "모두가 한 신호를 기다리고 있다" (동기화)
```

#### 🎬 컷 1-5: 카운트다운 (7~9s) — 영상의 핵심 음향 앵커
```
7.0s: 8bit BGM 완전히 멈춤 (음악 정지 = 태국식 감정 기법)
  배경도 아주 조용해짐 (PC방 팬음만 희미)

7.1s: 게임 카운트다운 음성 시작 (어린이 로봇 음성 아니 실제 어린이 목소리?)
  "3..." (낮은 톤, 첫음절 강조 "쓰~")
  
7.2s: 신호등 음향 "핑~" (높은 피치의 전자음, 신호등 점등음)
  빨강 신호등 점등과 동시

7.35s: "2..." (약간 높아진 톤)
  노랑 신호등 음향 "핑~" (약간 다른 톤, 더 맑음)

7.5s: "1..." (가장 높은 톤, 긴박함)
  초록 신호등 음향 "핑~" (가장 밝은 톤)

7.65s: "GO!" (폭발하는 느낌의 음성)
  동시에 부스터 점화음 "슈우우우~" (저음 ~ 고음 크레센도)

7.8s: 4명의 환호성 (동시 다중음향)
  "우아악!" "오!" "어엉!" "와!"
  각자의 톤이 다름 (주인공: 낮음, A: 높음, B: 중간, C: 매우 높음)

8.5s: 드리프트 타이어음 (첫 커브를 턴)
  "씨이이~" (타이어 음, 길게)

9.0s: 부스터 다시 점화
  "슈우~" (짧은 음)

감정 포인트: "음악이 정지되고 게임음만 남아있다" (몰입의 시작)
            "4명의 목소리가 겹치는 타이밍" (동시성)

🎯 이 카운트다운 음성 + 신호등음이 Part 3에서 **정확히 반복**됨 (강력한 신호)
```

## Part 2: 멈춤 (12~20s) — 게임음의 "유령"

### 음향 구조: 2 레이어 (현실음 + 심리음향)
1. **현실**: 지하철 엔진음, 역 안내음, 도시소음
2. **심리음향**: 게임음이 주인공 마음속에서만 울려남 (관객도 함께 들음)

### 장면별 상세 사운드 큐

#### 🎬 컷 2-1: 화면 암전 (12~14s) — 음악이 멎는 순간
```
12.0s: Part 1의 8bit BGM이 "아주 천천히" 페이드아웃 시작
  - 음계가 내려감 (슬픔의 신호)
  - "도.. 시.. 라.. 솔..." (음계의 역순, 하강)

12.3s: 모니터 전원 끄는 음 "슈..."
  - CRT 모니터의 고전압 방전음 (전자음, 높은 톤)
  - 2초에 걸쳐 서서히 사라짐

12.8s: 모니터들의 검은색이 확산되면서
  - 8bit 음악이 완전히 사라짐
  - 남는 것은 절대 침묵 (1초간 무음)

13.2s: 지하철 소음이 서서히 들려옴
  - 처음엔 매우 낮은 음량 (멀리서 접근하는 느낌)
  - 지하철 엔진음 (저음, 단조)

14.0s: 지하철 소음이 현재 음량에 도달 (하지만 여전히 우울)

감정 포인트: "시간이 점프했다" (음악의 음계가 내려감 = 슬픔)
            "게임 세상이 종료되었다" (모니터 전원음)
            "절대 침묵" = 타이밍 정지 (태국식 기법)
```

#### 🎬 컷 2-2: 현재 — 혼자 (14~17s)
```
14.0s~17.0s: 지하철 엔진음 지속 (저음, 반복되는 리듬)
  - "탁탁탁... 탁탁탁..." (차가운 기계음)
  - 가끔 차 떠나는 소리 "슥~"

15.2s: 주인공의 "숨" 소리가 들림 (아주 작게, 심리음향)
  - 숨을 깊게 쉬는 느낌 (스트레스, 고독함)

15.5s: 가끔 다른 승객 소음 (발자국, 옷 스치는 소리)
  - 하지만 모두들 조용함 (각자 폰을 들고 있음)

15.8s: 갑자기 **게임음이 희미하게 침투**
  - "핑~" (부스터 게이지 완성음)
  - 아주 낮은 음량 (주인공 심리 속에서만)
  - 지하철음 위에 희미하게 겹침

주인공 반응: 고개가 천천히 올라옴 (음향이 그를 깨움)

감정 포인트: **"게임이 자꾸 떠오른다"** (심리음향으로 표현)
            현실음과 게임음의 첫 겹침 (경계 흐릿해짐 시작)
```

#### 🎬 컷 2-3: 스쳐가는 옛날 생각 (17~20s)
```
17.0s: 주인공의 생각(플래시백) 시작
  - 지하철음은 여전하지만, 저음량
  - 마치 "멀리서 들리는 소음"처럼

17.5s: PC방 이미지가 주인공 머리 속을 스쳐감 (시각적 플래시백)
  - **Part 1의 카운트다운이 아주 희미하게 들림**
  - "3.. 2.. 1.." (거의 들리지 않는 수준)
  - 마치 오래된 기억에서 꺼내온 음향처럼

18.2s: 플래시백이 사라짐 (비어있는 PC방 책상들, 친구 없음)
  - 음향도 동시에 사라짐 (게임음 완전 소거)

18.5s: 폰이 울림 "띠리리~" (카톡 알림음)
  - 갑작스럽고 현대적인 음 (현실로 복귀)

감정 포인트: **"기억 속에 게임음이 남아있다"** (심리 리얼리티)
            현실과 기억의 오버랩

🎯 사운드로 "혼자"를 표현: 게임음의 유령처럼만 남아있음
```

## Part 3: 트리거 (20~28s) — 게임음이 현실을 깨운다

### 음향 구조: 3 레이어 (현실 + 게임음 + 심리)
### 감정 프레임: **태국식 "선택의 순간" 정지 기법 사용**

#### 🎬 컷 3-1: 카운트다운 음성 (20~22s)
```
20.0s: 폰 스피커에서 음악 재생 시작 (유튜브 영상)
  - 배경 음악(카트라이더 관련 추억 영상)
  - 하지만 주요는 음성

20.5s: **폰 스피커에서 Part 1의 카운트다운이 정확히 울려남**
  - "3..." (Part 1과 완전히 동일한 음성, 톤, 속도)
  - 지하철 소음은 갑자기 저음량으로 떨어짐

20.6s: 주인공의 **고개를 드는 동작**과 동시에
  - **음향 정지 0.3초** (태국식 감정 기법)
  - 지하철음도, 폰 음성도 잠깐 멈춤
  - 이 순간은 "선택의 순간" (과거를 인식하는 순간)

20.9s: 음향 복귀
  - 폰의 카운트다운 계속 "2..."
  - 지하철음 서서히 복귀 (하지만 저음량 유지)

21.5s: "1..." 들림
  - 점점 분명해지는 음성

22.0s: "GO!" (Part 1과 정확히 동일)
  - 이 순간, 주인공의 눈이 밖을 본다

감정 포인트: **음향 정지 = 시간 정지** (의식의 전환)
            과거 음성이 현재를 깨운다
```

#### 🎬 컷 3-2: 신호등 점등 (22~25s) — 현실이 게임 규칙으로 읽혀짐
```
22.0s: 창밖 터널 조명 점등 시작
  - 빨강 신호등 점등

22.1s: **신호등 점등음 = Part 1의 신호등음과 정확히 일치**
  - "핑~" (높은 피치, 선명한 전자음)
  - 이 음이 나는 순간, 관객도 "어? 이건 게임의 신호다"라고 인식

22.2s: 주인공의 얼굴에 빨강 빛이 비춰짐
  - 동시에 심장박동음 시작 (음향 디자인 요소)
  - "둡둡..." (천천하고 강렬)

22.5s: 노랑 신호등 점등
  - "핑~" (약간 다른 톤의 신호등음, Part 1과 동일)
  - 심장박동음 가속 "둡-둡둡..." (박자 증가)

22.8s: 초록 신호등 점등
  - "핑~" (가장 밝은 톤)
  - 심장박동음 극대 "둡둡둡둡..." (매우 빨라짐)

23.0s: **음향 정지 2 0.2초** (또 다시 태국식 정지 기법)
  - 신호등이 모두 켜진 상태에서 음향 정지
  - 이것은 "기대의 극대화"

23.2s: 심장박동음만 들림 (모든 다른 소음 제거)
  - "둡... 둡... 둡..." (천천해짐)
  - 마지막 박동음은 아주 강렬

23.5s~25.0s: 터널의 기둥들이 통과하면서
  - **게이트 통과음** (게임의 아이템 획득 음 같은 톤)
  - "핑핑핑..." (각 기둥마다 하나씩, 리듬감)
  - 마치 "현실이 게임의 트랙으로 인식되고 있다"는 신호

감정 포인트: **신호등 점등 = 게임의 신호등**과 동일
            현실이 점점 "게임 규칙"으로 읽혀짐 (인식 붕괴 시작)
            태국식 정지 기법으로 "기대의 극대화"

🎯 **Part 1의 음향이 정확히 반복**: 시청자에게 "이건 같은 신호다"라는 각인
```

#### 🎬 컷 3-3: 환상 (25~28s)
```
25.0s: 창밖에 4개의 그림자 형상이 보임 (친구들의 실루엣)
  - 게임음이 점점 명확해짐
  - 부스터 게이지 차는 음 "슈슈슈~" (여러 개 동시)

25.5s: 초등학생 목소리(주인공의 기억 속 음성)
  - "여기가 트랙이야" (A친구)
  - "나 1등 먼저 간다" (C친구)
  - "따라와" (B친구)

26.0s: 4명의 웃음소리가 겹침 (Part 1의 웃음과 동일한 톤)
  - "ㅋㅋㅋ" "하하하" (순수한 아이들 웃음)

26.5s: 심장박동음이 다시 울려옴 (강렬)
  - "둡-둡-둡-둡-둡!" (매우 빨라짐)

27.2s: 모든 소음이 한순간 멈춤
  - **절대 침묵** 1초 (태국식 감정 극대화)

27.8s: 부스터 폭발음 한 방 "슈우우우!!!"
```
