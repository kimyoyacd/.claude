# 기획파트 브리프 — 전략·키메시지·제안서

> 담당 산출물: 팩트북 / 전략·컨셉·키메시지 / 소재·프로모션 IDEA / 미디어·버젯 플랜 / 제안서 3종(각 10p PPT)
> 핵심 일정: 컨셉 7.13~14 → 키메시지 7.15 → SB 브리프 7.20~21 → 제안서 1차 7.28 / 2차 7.30 → 마감 7.31

## 1. 전략 프레임 (제안서 논리 라인)

**문제정의 → 인사이트 → 전략 → 키메시지 → 크리에이티브 → 미디어 → 운영. 하나의 실로 꿴다.**

1. **문제정의**: 카트라이더는 두 번 멈췄다(2023 원작 종료, 2025 드리프트 종료). 남은 것은 그리움과 불신의 공존 — "돌아와줬으면 좋겠지만, 또 접을까 봐 무섭다."
2. **인사이트**: 타겟(2030 남성)에게 카트라이더는 게임이 아니라 **유년기의 공용 언어**다. PC방, 방과 후, 친구, 부스터 소리. 이들이 원하는 건 신작이 아니라 **그 감각으로 돌아갈 자격과 명분**이다.
3. **전략**: 하이프형 신작 마케팅 ❌ → **'귀환의 서사' 3단 퍼널**
   - 사전예약(26년 하반기~): "기억 소환" — 노스탤지어 트리거로 원년 유저 재점화, 사전예약 = 재회의 약속
   - CBT(27년 초): "신뢰 검증" — 코어 유저·인플루언서 중심, 18/19 스피드전 감각 재현을 직접 확인시키는 단계 (플러스알파 제안)
   - 런칭(27년 내): "전 국민 재출발" — 시네마틱 영상 + 대규모 미디어 버스트, 아이템전 캐주얼함으로 20대 신규 확장
4. **기대치 관리 원칙**: '복각'이라는 단어 금지. "추억 그대로"가 아니라 **"그때의 감각, 지금의 게임"**. 제품이 못 지킬 약속은 광고가 먼저 하지 않는다.

## 2. 키메시지 후보 (7.15 확정용, 안 3+1)

| 안 | 키메시지 | 의도 | 리스크 |
|---|---|---|---|
| A (推) | **"다시, 출발선."** | 종료의 역사를 부정하지 않고 '재출발'로 승화. 짧고 확장성 높음(다시, 부스터. / 다시, 그 트랙. 시리즈 카피 전개 가능) | 담백해서 임팩트 보강 필요 — 비주얼/사운드로 채움 |
| B | **"너의 부스터는 끝나지 않았다"** | 유저 개인의 서사에 말 걸기. 감성 자극 직접적 | 다소 김. 배너 가독성 확인 |
| C | **"국민 레이싱, 다시 달린다"** | '국민 게임' 포지셔닝 정면 승부. 대중 확장성 | 원년 유저에겐 덜 개인적 |
| 서브카피 공통 | "추억은 복각하지 않는다. 다시 달릴 뿐." | 기대치 관리 + 제품 철학(현대화 빌드) 방어 논리 | — |

**키메시지 구성 의도 문서(10p) 목차안**: ①유저 정서 진단(커뮤니티 VOC) ②메시지 도출 로직(3안 비교) ③메인+서브 카피 체계 ④단계별(사전예약/CBT/런칭) 메시지 변주 ⑤적용 예시(배너/영상/이벤트 페이지)

## 3. 제안서 3종 구성안 (각 10p 이내)

**① 사전예약 캠페인 제안서**: 1 표지 / 2 유저 정서 진단 / 3 캠페인 컨셉 / 4-5 배너 2종 시안+의도 / 6 사전예약 보상·바이럴 아이디어(추억 아이템 지급 등) / 7 이벤트 페이지 시안(플러스알파) / 8 미디어 믹스 / 9 KPI·운영 / 10 로드맵

**② 런칭 캠페인 제안서**: 1 표지 / 2 런칭 국면 정의(사전예약→CBT 자산 승계) / 3 캠페인 컨셉 / 4-6 **시네마틱 영상 1종** 트리트먼트+보드 / 7 배너 2종 시안 / 8 미디어 버스트 플랜 / 9 쇼케이스·인플루언서·프로모션 연계 / 10 KPI·러쉬플러스 시너지

**③ 키메시지 제안서**: 위 2번 목차안 참조

**+ 인력·단가 제안**: 전담팀 조직도(전담 비율 명시), 타이틀별 담당자 직급/경력, 제작팀 구성, 유형별 단가표(배너/영상/페이지/운영). 장기 대행 안정성(백업 인력, 리포트 체계) 한 장 포함 — 평가 3.1/3.2 직결.

## 4. 러쉬플러스 파트 (누락 금지)

- 목표: 휴면 7일+ 유저 재유입, 시즌(2개월 주기)·콜라보(연 4~5회) 이슈 캘린더형 운영
- 제안 프레임: 연간 이슈 캘린더 1장 + 휴면 리타겟팅(푸시/미디어/복귀 보상 연계) 플로우 1장 + 콜라보 증폭 플레이북 1장 — 컴팩트하게 3장 이내
- 크레이지레이싱 카트라이더와의 **크로스 프로모션**(러쉬플러스 유저 → PC 신작 사전예약 유도) 아이디어로 "두 타이틀을 하나의 IP 생태계로 본다"는 시각 어필
