## color-combo-generator

제안서 표지 등에 쓸 컬러 조합을 카드 형태로 자동 생성해주는 정적 웹 앱입니다. 빌드·서버 없이 `color-combo-generator/color-combo.html` 파일 하나만 브라우저로 열면 바로 사용할 수 있습니다.

- 스페이스바 한 번에 조합 카드 4장 생성 — 각 카드는 풀블리드 색 블록 + 상대 색으로 찍힌 색 이름·헥스코드로 조합이 한눈에 느껴지는 구성
- 무드 칩(표지 추천/비비드/파스텔/어시/무디/믹스)과 색 개수(2~4)만 고르면 배색 이론은 자동 적용
- 블록별 "바꾸기" 버튼으로 마음에 안 드는 색만 조화롭게 다시 뽑기, 카드 "고정"으로 유지
- 색 블록 클릭 = 헥스코드 복사, 카드 단위 HEX 목록 복사·PNG 저장
- 스포이트(EyeDropper API)로 화면 어디서든 색을 집어 헥스코드로 추출 (Chrome/Edge)
- 이미지를 업로드하면 대표 색상을 추출해 조합 카드로 변환
- 고정·복사·저장한 조합은 로컬에 쌓이고 클릭 한 번으로 다시 불러오기
