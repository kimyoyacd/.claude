## color-combo-generator

제안서 표지 등에 쓸 컬러 조합을 자동으로 만들어주는 정적 웹 앱입니다. 빌드 없이 `color-combo-generator/index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

- 색상 개수(2~5), 배색 방식(보색/유사색/삼각·분리보색/사각배색/단색조), 무드(다크+파스텔/비비드/파스텔/어시/무디)를 조합해 팔레트를 생성
- 표지 미리보기 카드로 실제 적용 느낌 확인, HEX 목록·CSS 변수 복사, PNG로 저장
- 스포이트(EyeDropper API)로 화면 어디서든 색을 집어 팔레트에 추가 (Chrome/Edge)
- 이미지를 업로드하면 대표 색상을 자동으로 추출해 HEX 코드로 제공
- 최근 생성한 조합을 로컬에 기록해두고 다시 불러오기 가능
